# 🔐 Tela de Login

Interface de login com efeito glassmorphism (vidro fosco), desenvolvida com HTML e CSS puro.

## ✨ Funcionalidades

- Design com efeito de vidro (glassmorphism) e imagem de fundo
- Campos de usuário e senha com ícones (Boxicons)
- Opção "Lembrar senha" e link "Esqueci a senha"
- Botão com animação de hover
- Link para cadastro de novo usuário

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (glassmorphism, backdrop-filter, transições)
- Boxicons (ícones)
- Google Fonts (Kanit, Poppins)

## 📌 Status

Projeto pessoal desenvolvido para praticar estilização avançada com CSS.
